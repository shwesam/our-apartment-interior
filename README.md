# Our Apartment Interior Showcase

Responsive mobile + desktop interior design showcase for the apartment.

## Included
- Latest apartment floor plan
- Living + TV unit
- Kitchen
- Foyer
- Dining + crockery
- Puja
- Bedrooms 1–3
- Toilets
- Utility balcony

The latest Kitchen, Dining + Crockery, Puja, and Living + TV sections use one presentation image each instead of separate color-option boards.

## Run locally
Open index.html directly, or run:

```bash
python -m http.server 8000
```

Then open http://localhost:8000.
